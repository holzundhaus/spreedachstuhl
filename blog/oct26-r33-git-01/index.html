Dachstuhl: Wie baut man eine nachvollziehbare Bestandsliste auf?

Eine tabellarische Vorlage versieht Bauteile, Zustand, Fotos und Unklarheiten mit stabilen IDs.

Ihr Vorhaben

Beschreiben Sie Ihre Idee zu Dachstühle. Der Anfrageversand wird vorbereitet; aktuell werden keine Angaben übermittelt.

Der Versand ist noch nicht freigeschaltet.

Eine Bestandsliste ist mehr als eine Liste von Bauteilnamen. Sie verbindet einen eindeutig bezeichneten Ort mit beobachtbaren Angaben und zeigt zugleich, wo Wissen fehlt. Ihr Nutzen liegt in der Nachverfolgbarkeit: Spätere Rückfragen beziehen sich auf denselben Eintrag statt auf wechselnde Beschreibungen wie links, hinten oder an der Ecke.

Ausgangslage: Dachstuhl

Bei einem Dachstuhl muss eine Eigentümerbeobachtung von einer Aussage über die Konstruktion getrennt bleiben. Die Unterlagen sollen die fachliche Besichtigung vorbereiten.

Für dieses Arbeitsbeispiel werden vier Bezugspunkte verwendet: sichtbarer Abschnitt, Bezug zur Dachseite, vorhandene Unterlagen und Zugangsgrenze. Die Leitfrage lautet: Welche Stelle ist beobachtet und welche Aussage über verdeckte Bereiche wäre nur eine Vermutung?

Ein kleines Register mit stabilen Kennungen

Eine Kennung je Bereich vergeben

Wählen Sie kurze IDs, die auch auf Fotos und einer Standortskizze vorkommen. Ändert sich später eine Bezeichnung, bleibt die ursprüngliche ID erhalten. Neue Bereiche erhalten neue Kennungen.

Feststellung und Annahme getrennt erfassen

Ein sichtbarer Zustand kommt in das Beobachtungsfeld. Angaben aus alten Plänen werden als Quelle gekennzeichnet. Ungeprüfte Vermutungen gehören in eine eigene Spalte und werden nicht als Bestandsdaten ausgegeben.

Offene Punkte zuordnen

Für jede ungeklärte Eigenschaft wird eine konkrete Frage ergänzt. Notieren Sie, welcher Nachweis sie beantworten könnte und wer die fachliche Einordnung übernehmen soll.

Eine Vorlage für das nächste Gespräch

Die Vorlage besteht aus Bereich-ID, Standort, Beschreibung, Beobachtung, Foto-ID, vorhandener Quelle, ungeklärter Eigenschaft und nächstem Schritt. Beginnen Sie mit wenigen gut bezeichneten Bereichen. Ein vollständig ausgefülltes, aber geratenes Register ist weniger hilfreich als eine kurze Liste mit offen ausgewiesenen Lücken.

  • Sichtbarer abschnitt: Beobachtung / Wunsch / offene Frage / nächste Klärung
  • Bezug zur dachseite: Beobachtung / Wunsch / offene Frage / nächste Klärung
  • Vorhandene unterlagen und zugangsgrenze: Beobachtung / Wunsch / offene Frage / nächste Klärung

Das Beispiel ist eine Arbeitsvorlage, kein dokumentiertes Kundenprojekt. Übertragen Sie nur die Bezugspunkte, die bei Ihrem Vorhaben tatsächlich vorhanden sind; fehlende Angaben bleiben sichtbar offen.

So bleibt die Notiz brauchbar

Bewahren Sie frühere Fassungen auf und versehen Sie jede Änderung mit Datum und Anlass. Damit wird erkennbar, ob ein Eintrag durch eine neue Beobachtung oder nur durch eine andere Formulierung geändert wurde. Das Register unterstützt die Vorbereitung und Zusammenarbeit; es ersetzt keine Bestandsuntersuchung und keine Aussage über Tragfähigkeit oder Ausführungseignung.

Zur Einordnung des Ausgangsthemas: Spreedachstuhl. Die hier gezeigte Arbeitsvorlage ergänzt diese Informationen für die Vorbereitung eines eigenen Gesprächs.
